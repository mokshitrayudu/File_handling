# 📁 File handling

A simple command-line file manager in Python. Create, read, update and delete files from the terminal using `pathlib`.

## Features

- **Create** a new file with content
- **Read** an existing file
- **Update** a file: rename it, overwrite it, or append to it
- **Delete** a file

## Usage

```
press 1 for creating a file
press 2 for reading a file
press 3 for updating a file
press 4 for deletion a file
```

Enter a number, then follow the prompts.
